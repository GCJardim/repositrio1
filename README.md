# ADESAI2.0 — Registro de continuidade

Este repositório documenta o desenvolvimento do aplicativo web institucional **ADESAI2.0**.

**Aplicativo publicado:** https://adesai2-0.vercel.app/

## Comece por aqui (para outros chats / desenvolvedores)
1. Leia [CONTINUIDADE.md](CONTINUIDADE.md) antes de alterar qualquer coisa.
2. Leia [STATUS_ATUAL.md](STATUS_ATUAL.md) para conferir o estado conhecido, sem confundir solicitações com entregas verificadas.
3. Consulte [HISTORICO.md](HISTORICO.md) para o registro cronológico de mudanças e seus testes.
4. Consulte a Vercel e o código real antes de alterar: **o repositório não é, ainda, um espelho completo do aplicativo**.

## Regra de manutenção
- Registrar cada trabalho efetivamente concluído e testado.
- A cada **5 entregas confirmadas**, consolidar o estado do aplicativo em STATUS_ATUAL.md e CONTINUIDADE.md.
- Não registrar pedidos pendentes como funcionalidades concluídas.
- Jamais colocar credenciais, tokens, dados pessoais dos participantes ou dados de produção nos arquivos públicos.

Última atualização: **18/11/2026**.
